# NexusAI — Futuristic Dark Mode SaaS Landing Page

İlandaki tüm UI/UX isterlerine birebir uygun olarak hazırlanmış, portfolyo ve canlı demo amaçlı kullanıma hazır SaaS açılış sayfası projesi.

## Özellikler
- **Fütüristik Karanlık Mod (Obsidian Dark):** Elektrik moru (`#a855f7`) ve camgöbeği (`#22d3ee`) neon vurgular.
- **İnteraktif Dashboard & Pipeline Önizlemesi:** Canlı telemetri göstergeleri ve veri akış animasyonlu düğümler.
- **Bento-Grid Mimari:** Modern SaaS özelliklerini sergileyen ızgara kartları ve kod önizlemesi.
- **Aylık / Yıllık Geçişli Fiyatlandırma Tablosu:** JavaScript ile anlık fiyat hesaplayan 3 kademeli planlar.
- **SSS (FAQ) Akordiyonu & Kaydırma Animasyonları:** Tamamen duyarlı (Responsive) yapı.

## Nasıl Canlıya Alınır? (Ücretsiz ve Hızlı)
1. **Netlify Drop / Vercel / GitHub Pages:** Bu klasörü doğrudan [app.netlify.com/drop](https://app.netlify.com/drop) üzerine sürükleyip bırakarak saniyeler içinde `https://proje-adin.netlify.app` şeklinde canlı bir link alabilirsin.
2. **Framer'a Aktarım:** Framer içerisinde *"HTML to Framer"* eklentisini kullanarak canlıya aldığın bu URL'yi tek tıkla düzenlenebilir Framer katmanlarına dönüştürebilirsin.
